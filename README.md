### 💸 [Finora](https://github.com/TusharLokhande/Finora) &nbsp;·&nbsp; [live ↗](https://finora.efficanova.com/)

A fast, minimal personal finance app for expenses, income, credit cards and monthly budgets, built and run end to end.

```diff
+ React 19 + TypeScript client · .NET 10 Clean Architecture API · PostgreSQL
+ Money stored as integer minor units; balances derived, never stored, so they can't drift
+ Per-user isolation enforced twice: app-level scoping + composite foreign keys in Postgres
+ Google OAuth 2.0 (PKCE), JWT + HttpOnly refresh cookie, admin approval flow with audit log
+ CI/CD: GitHub Actions → GHCR → SSH deploy → Traefik (TLS) · separate prod and dev envs
+ OpenTelemetry traces, metrics and logs · health probes · xUnit tests on money-critical logic
```

### 📡 [observability-stack](https://github.com/TusharLokhande/observability-stack)

A self-hosted observability stack in Docker Compose that my apps report into.

```diff
+ OpenTelemetry Collector → Prometheus (metrics) · Loki (logs) · Tempo (traces)
+ Grafana with provisioned data sources, ready to use on first boot
```
